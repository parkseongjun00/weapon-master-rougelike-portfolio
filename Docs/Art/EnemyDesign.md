## 0. 일러두기

1. 게임 콘셉트와 전투 규칙은 [GDD](../GDD.md) 1장·6장을 기준으로 한다. 이 문서는 적의 외형·성격·표현을 담당한다.
2. 확정 기준과 Codex 제안·검토 후보를 구분한다. 후보는 실제 제작이나 공격 규칙 변경의 근거로 사용하지 않는다.
3. 긴 선택지 비교는 해당 작업 세션 안에서 진행한다. 장기 보류는 [Backlog](../Backlog.md)에 두고, 채택 결과는 이 문서의 기준에 반영한다.
4. 디자인 검토 승인과 이미지 생성·모델 제작·씬 적용 승인은 구분한다. 실제 제작 범위는 해당 작업 요청에서 확인한다.
5. 과거 슬라임·로봇 탐색과 기존 테스트 리소스는 현재 제작 기준과 구분한다. 기존 리소스의 교체·삭제는 이 문서 작성만으로 실행하지 않는다.
6. 문체와 갱신 절차는 [WritingGuide](../WritingGuide.md)를 적용한다. 결정의 변화는 변경 이력에 기록한다.

## 1. 공통 방향

- 사용자 논의 후보: 사람형 거리 싸움꾼·건달 패거리. 적의 최종 정체성은 디자인 세션에서 검토·선택한다.
- 검토 가능성: 적 집단의 개성과 관계를 스토리텔링의 기반으로 사용할 수 있다.
- 사용자 승인: 스테이지는 다양한 장소로 확장할 수 있다. 한국 먹자골목은 첫 스테이지이며, 게임 전체의 적을 해당 장소에만 한정하지 않는다.
- 사람형 후보의 검토 사유: 돌발적인 싸움에서 주변 물건으로 대응하는 상황을 상상하게 하는 접점을 검토한다.
- 미확정: 적의 종별·집단 구성, 조직명·목적·규칙, 대장과 구성원의 관계, 싸움이 발생하는 사건.
- 미확정: 정식 타이틀과 '야차'의 세계관 내 의미. '야차 시뮬레이터'는 후보 표현이다.

---

## 2. 참고 자료의 활용 기준

- 사용자 참고: "짱구는 못말려" 극장판에 등장할 법한 개성 있는 패거리의 인상.
- Codex 해석·검토 후보: 자신들은 진지하지만 관객에게는 우스운 허세, 유난스러운 복장과 조직 문화, 구성원 사이의 티격태격.
- 참고에서 사용할 특징을 개별 디자인 검토 시 명시한다. 기존 작품의 캐릭터·복장·문양을 그대로 제작 기준으로 삼지 않는다.
- 작품별 등장 집단의 정확한 명칭과 세부 설정은 이번 문서 작성에서 검증하지 않았다.

---

## 3. 외형과 가독성

- 디자인 검토 기준: 쿼터뷰에서 적과 플레이어, 적의 몸체와 손에 든 물건을 구분할 수 있어야 한다.
- 디자인 검토 기준: 여러 적이 동시에 표시될 때 체형·자세·색 배치로 역할을 파악할 수 있어야 한다.
- 디자인 검토 기준: 선택한 적 콘셉트가 다른 스테이지와 어떻게 연결되는지 확인한다.
- Codex 검토 후보: 체격, 헤어스타일, 유난스러운 복장과 포즈를 개별 적의 구분 수단으로 사용한다.
- 미확정: 신체 비율, 치비 여부, 의상·문양·색상, 얼굴 표현, 모델·재질·텍스처 예산.

---

## 4. 행동과 연출

- 확정 규칙: 적의 유형별 공격과 피해 조건은 GDD 6.1을 따른다.
- 기존 Enemy_Grunt_01 모델을 재사용해 공격 유형을 구분할 수 있으며, 신규 모델 제작은 유형 추가의 필수 조건이 아니다.
- 공격 예고·유효 시점·회복 상태와 유형별 역할을 게임 시점에서 구분할 수 있도록 표현한다.
- 표현 검토: 선택한 적 콘셉트의 접근·공격·피격 동작이 현재 피해 규칙과 함께 납득되는지 확인한다.
- Codex 검토 후보: 과장된 휘청거림·넘어짐, 허세 섞인 대사, 기절·리타이어로 읽히는 퇴장.
- 미확정: 출혈, 피격 효과음, 총기의 사실성, 사망·퇴장 표현. 기절 연출 채택은 현재 HP·XP·필드 제거 규칙의 자동 변경을 뜻하지 않는다.
- 공격 거리·주기·판정·AI 동작의 변경이 필요하면 GDD에서 별도로 확정한다.

---

## 5. 대표 적 검토

- 대상: 현재 대표 모델과 이를 재사용하는 공격 유형의 표현 검토.
- 현재 적용: 사용자 지정 Enemy_Grunt_01 모델을 단일 범용 적으로 적용하고 대기·달리기 애니메이션을 연결했다.
- 기존 사람형 펀치를 공통 모션으로 재사용하며 선택 퇴장 연결을 유지한다.
- 기본 펀치는 접근 후 정지·방향 확정·타격 창·회복으로 연결했다. 별도 예고 모션 제작은 첫 플레이 결과 후 판단한다.
- 구현 구분: 몸체 접촉 피해를 제거하고 손 타격 창으로 전환했다. 정지 전신/이동 하체 표현·피해·퇴장·재사용의 사용자 확인은 대기다.
- 전체 적 정체성·조직·분위기와 후속 개별 디자인은 미확정이다.
- 실제 적용·검증과 중요한 코드 안내는 [적 애니메이션 개발 노트](../DevNotes/05-EnemyAnimation.md)에 기록했다.
- 다음 검토 결과물: 정체성 한 문장, 실루엣·복장·체형의 설계안, 접근·공격·피격·퇴장 표현안, 신규 기능 필요 여부.
- 검토 순서: 적 콘셉트 검토·선택 → 문서 설계안 확인 → 제작 범위 요청 → 대표 리소스 확인 → 실제 게임 시점 확인 → 후속 적 확대 판단.
- 제작 판단 기준: 캐릭터 성격, 전투 가독성, 게임 콘셉트와의 연결, 기존 전투 규칙과의 연결.

## 6. 후속 후보와 열린 질문

| 항목 | 현재 상태 | 다음 판단 |
|---|---|---|
| 투척 건달 | Codex 추천 후보 | 첫 원거리 적으로 채택할지, 던질 물건과 동작을 정할지 검토 |
| 새총·폭죽·개조 발사기 | 대안 후보 | 분위기·가독성·제작 비용 비교 |
| 성급한 적·덩치 큰 적·거리 유지 적 | 역할 후보 | 적 유형 확장 시 규칙과 디자인을 함께 검토 |
| 적이 바닥 물건을 집어 사용 | 장기 기능 후보 | [Backlog 18](../Backlog.md#18-적의-물건-확보와-원거리-공격-확장) 참고 |
| 추가 장소의 적 디자인 | 장소·수량 미확정 | 공통 정체성과 장소별 변형 범위를 검토 |

- 조직·외형·연출의 구체적인 선택지는 해당 작업 세션에서 비교하고, 채택 결과를 이 문서에 반영한다.
