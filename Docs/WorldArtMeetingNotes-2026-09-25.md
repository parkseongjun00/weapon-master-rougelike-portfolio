## 0. 일러두기

1. '사용자 방향'은 사용자가 직접 원하거나 당분간 기준으로 삼겠다고 한 내용이다. 최종 확정 명세와는 구분한다.
2. '제안·실험'은 Codex의 제안 또는 이미지 생성 결과다. 사용자의 별도 채택 없이 확정 사항으로 취급하지 않는다.
3. 이 문서는 대화의 전체 발언록이 아니라 다음 논의를 시작하는 데 필요한 내용만 추린 회의록이다.
4. 2026-10-11 현재 첫 맵은 공원에서 가상의 한국 먹자골목·상가 거리로 변경되었다. [첫 맵 기준](Art/FirstMap.md)을 현재 기준으로 읽는다. 아래 공원 관련 표현과 '다음 대화의 출발점'은 2026-09-25 당시 논의 기록이며, 현재 제작 지시로 사용하지 않는다. 그 밖의 미확정 아트 의견도 이 안내만으로 확정되지 않는다.
5. 현재 게임 콘셉트는 여러 장소에서 싸울 수단을 확보·교체하는 즉흥 전투다. 적 정체성과 비주얼 분위기는 디자인 세션에서 검토한다. 현재 기준과 검토 상태는 [GDD](GDD.md)와 [적 디자인 문서](Art/EnemyDesign.md)를 읽는다. 아래 슬라임·과거 적 탐색은 당시 기록이며 현재 적 제작 지시가 아니다.

## 1. 논의 목적과 현재 판단

- 사용자 목표: 무기·몬스터·도시 배경이 하나의 인상적인 세계로 읽히도록 세계관, 콘셉트, 아트 리소스 방향을 함께 정한다.
- 사용자 판단: 조작과 전투의 재미 외에, 첫인상과 공유할 만한 콘셉트도 플레이 유입에 기여해야 한다.
- 사용자 방향: 현재 아트 리소스는 필요하면 전면 교체할 수 있다.
- 사용자 방향: Codex의 개발 작업과 병행해 Meshy AI로 리소스를 시험 제작한다.
- 미반영 사항: 세계관·아트 방향을 콘텐츠 확장보다 앞당기자는 의견이 있었으나, `DevPlan.md`의 단계 순서는 이 회의록에서 변경하지 않는다.

## 2. 세계와 배경

- 사용자 방향: 도시를 배경으로 삼고, 첫 아레나의 출발점은 올림픽공원 같은 규모의 도시 공원으로 잡는다.
- 논의된 인상: 친숙하고 밝은 공원과 비일상적인 전투의 대비. 도시의 나머지 구역은 이후 맵을 바꿔 확장할 수 있다.
- 미확정: 공원의 구체적인 외형, 도시 이름, 시간대, 사건의 원인, 적의 정체와 세계관의 핵심 문장.
- 검토만 한 아이디어: 밤에는 몬스터와 싸우고 낮에는 도시를 정리하는 두 트랙 구조. 게임 루프 변경으로 이어지므로 채택되지 않았다.
- 기각: '누군가의 간절한 열망이 무기가 된다'는 설정은 사용자가 명시적으로 기각했다.
- 보류: '무기에 사람의 영혼이 깃든다'는 발상은 흥미롭지만, 무기를 자주 교체하고 버리는 현재 게임 동작과 충돌할 수 있다. 깊은 설정으로도 채택하지 않았다.

---

## 3. 무기와 적의 콘셉트

- 사용자 방향: 판타지 무기에 한정하지 않고 야구 방망이, 권총, '브루클린 배트' 같은 현대적 무기도 등장시킨다.
- 기획 과제: 서로 다른 시대와 용도의 무기가 같은 공원에 나타나는 이유를 시각적 규칙 또는 세계관의 사건으로 설명한다.
- 사용자 선택: 첫 적 모델과 움직임을 시험할 대상으로 무난한 슬라임을 사용한다.
- 슬라임 이미지 실험: 정면을 보는 청록색 계열의 단순한 젤리형 적. 이 디자인은 테스트용이며 적 세력 전체의 미술 기준으로 확정되지 않았다.
- 애니메이션 논의: 슬라임은 복잡한 리그보다 시각 메시의 늘어남·눌림, 위아래 움직임, 필요하면 셰이더 보조 효과로 유휴·이동·피격을 표현하는 방향을 제안했다. 구현 결정은 아니다.
- 미확정: 슬라임 이외의 적 무리, 적 간 시각적 공통점, 몬스터가 공원에 출현하는 이유.

---

## 4. 아트 스타일

- 사용자 취향: 밝고 캐주얼하며 친근한 캐릭터. 약간의 개성과 미스터리는 원하지만, 과하게 잘생기거나 영화 포스터처럼 정교한 표현은 원하지 않는다.
- 탐색 방향: 형태가 읽히는 스타일라이즈드 3D. Unity URP 환경과 다수의 적이 동시에 보이는 쿼터뷰를 고려한다.
- 대화 중 제시한 시험 기준: 플레이어 약 10~20K 삼각형, 일반 적 약 1.5~4K 삼각형 등. 이는 제작 검증 전의 예산 제안이며 확정 규격이 아니다.
- 미확정: 최종 조명·색 팔레트·재질·UI·환경 소품 기준.

---

## 5. 플레이어 캐릭터 이미지 실험

- 사용자 콘셉트: 평범하게 공원을 걷던 사람처럼 보이지만, 아무 무기나 쥐어도 능숙하게 다루는 '웨폰마스터'. 예상치 못한 전투에 놀라면서도 몸은 익숙하게 대응하는 인상.
- 확정된 서사 아님: 과거 비밀 요원 같은 경력은 분위기를 설명하는 예시로만 사용했다.
- 현재 이미지 방향: 짙은 청록색 캐주얼 재킷, 밝은 상의, 어두운 바지, 붉은 갈색 운동화, 작은 갈색 백팩. 크로스백과 손에 든 무기는 제외했다.
- 손 형태: 손가락 애니메이션 부담을 줄이기 위해 손가락을 분리하지 않은 단순한 쥔 주먹을 선호한다. 완전한 구형 손은 사용자 피드백으로 제외했다.
- 얼굴: Meshy 리메시 이후 생기는 울퉁불퉁한 표면과 짙은 그림자를 줄이려 매끈한 얼굴형을 시험했다. 이후 사용자가 제시한 이전 스타일의 갈색 홍채와 생기 있는 눈을 다시 적용했다.
- 포즈: 정면 T-pose, 좌우 대칭, 수평으로 뻗은 팔, 일정하게 분리된 곧은 다리, 서로 평행하게 정면을 향하는 발을 목표로 여러 차례 수정했다.
- 마지막 생성 이미지: `개발 환경의 로컬 시안 경로(공개본 제외)`. 대화용 시안이며 Meshy 생성·리깅 결과는 아직 검증되지 않았다.
- 배경 제거 이미지의 검은 미리보기는 투명 영역 표시 방식일 수 있다. 다만 이미지 생성 방식의 배경 제거는 원본 픽셀의 완전한 보존을 보장하지 않으므로 최종 사용 전 가장자리와 알파를 다시 확인해야 한다.

## 6. 다음 대화의 출발점

1. 공원과 도시에서 벌어지는 사건을 한 문장으로 정의한다. 현재 무기 교체 게임플레이와 양립해야 한다.
2. 무기군과 적 무리를 묶는 시각적 규칙을 정한다. 슬라임은 첫 시험 대상으로 두고 다른 적은 별도로 기획한다.
3. 플레이어·적·공원에 공통으로 적용할 아트 기준을 정한다. Meshy 시안과 실제 Unity 조명 결과를 함께 본다.
4. 리소스 예산은 후속 제작 범위와 함께 검토한다.
5. 합의가 끝난 항목만 성격에 맞는 기준 문서로 이관한다. 이번 회의록 자체는 구현 명세가 아니다.
