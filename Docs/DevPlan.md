## 3. 적 이동·공격 확장

| 순서 | 계획 |
|---|---|
| 1 | 적 프리팹·생성 위치·사망·풀 재사용 흐름 구성 |
| 2 | 몸체 기반 다중 링·예약·포위·안쪽 충원 구성 |
| 3 | NavMesh 경로 추종·장애물 우회·개체 회피 연결 |
| 4 | 공통 무기·모션 경로를 사용하는 기본 적 펀치 적용 |
| 5 | 원거리 견제형부터 검토하고 현장 무기 활용형으로 이어가며 유형별 규칙·제작 범위 선정 |
| 6 | 선정한 유형을 대표 적으로 구현하고 공격·이동·재사용 확인 |
| 7 | 무기별 대응을 비교한 뒤 적 구성과 유형 확대 |

- 후속 적 유형 확장은 대표 무기의 역할·사용 확인 뒤 재검토하는 기존 순서를 유지한다. 공격 유형 검토에는 기존 대표 모델을 재사용할 수 있으며 새 모델 제작을 필수 조건으로 두지 않는다.
