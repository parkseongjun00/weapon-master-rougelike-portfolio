## 1. 플레이어·카메라

### 1.1 이동·입력

<a id="1-플레이어-이동조작"></a>

| 기능 | 포함 내용 |
|---|---|
| 이동 | WASD·방향키 입력 |
| 조준·공격 입력 | 마우스 방향 조준, 캐릭터 회전과 공격 입력 |
| 상호작용 입력 | 무기 획득·교체·드롭 버튼 |
| 입력 통합 | 조준 벡터 공통 처리와 Input System 입력 바인딩 |

- 입력별 동작은 [GDD 6.3](GDD.md#63-조작)을 따른다.

### 1.3 카메라

<a id="3-카메라"></a>

| 기능 | 포함 내용 |
|---|---|

| 충돌·가림 대응 | 건물 충돌·상체 기준점 시야 가림 시 거리 축소와 이탈 후 복원 |
| 주시 높이 보정 | 장애물 보정으로 가까워지는 정도에 따른 주시 높이 보간 |

- 전신·주변 전투 공간의 상시 노출은 보장하지 않는다.

## 2. 맵·적

### 2.1 맵·공간

<a id="2-맵공간-구조"></a>

| 기능 | 포함 내용 |
|---|---|
| 제한형 공간 | 고정된 플레이 공간과 이동 경계 |
| 무한형 공간 | 플레이어 이동에 따른 공간 생성·재활용과 활성 범위 관리 |
| 첫 맵 | 한국 먹자골목·상가 거리의 제한형 공간과 통행 제외 영역 |

- 공간 유형의 적용 범위는 [GDD 3장](GDD.md#3-런run-구조), 첫 맵의 배치·환경 기준은 [맵 디자인](Design/MapDesign-KoreanFoodStreet.md)을 따른다.

---

### 2.2 적 이동·공격

<a id="6-적-시스템"></a>

| 기능 | 포함 내용 |
|---|---|
| 적 유형·프리팹 | 유형별 공격·표현 연결과 유형 확장 기반 |
| 접근·포위 | 몸체 크기 기반 다중 링·자리 예약·안쪽 충원·수용량 초과 대기 |
| 목표 추적 | 목표 위치·도착 상태 관리와 대상 이동 시 재추적 |
| 이동 경로 | NavMesh 경로 추종·장애물 우회·주변 개체 회피 |
| 유형별 공격 | 시작 조건·예고·유효 시점·범위·방향 확정·빗나감·공격 후 회복 처리 |
| 기본 적 펀치 | 공통 무기·모션을 사용하는 주먹 판정과 플레이어 피해 적용 |
| 공격 상태 정리 | 사망·비활성화·풀 재사용 시 공격·판정·모션 상태 정리 |

- 행동·공격 규칙은 [GDD 6.1](GDD.md#61-적-행동과-공격-규칙), 개별 유형과 표현의 검토 상태는 [적 디자인](Design/EnemyDesign.md)을 따른다.

---

### 2.3 적 생성·사망

| 기능 | 포함 내용 |
|---|---|
| 생성 위치 | 제한형은 경계 부근, 무한형은 플레이어 주변 활성 범위에서 일정 거리 이상 떨어진 위치 선택 |
| 안전한 생성 | 보행 바닥·맵 범위·장애물 및 캐릭터 겹침 검사와 후보 실패 시 해당 주기 생략 |
| 출현 빈도 | 시간 경과에 따른 스폰 간격 감소 |
| 체력·사망 | 적 HP·피해 처리와 사망 즉시 전투 대상 제외 |
| 퇴장·제거 | 이동·공격·피격 판정 종료와 선택 퇴장 표현 후 제거 |

- 생성·사망 규칙은 [GDD 6.1](GDD.md#61-적-행동과-공격-규칙), 시간별 난이도는 [GDD 6.2](GDD.md#62-난이도-곡선-엔드리스)를 따른다.

## 3. 무기·전투

### 3.1 무기 데이터·스폰

<a id="4-무기-시스템"></a>

| 기능 | 포함 내용 |
|---|---|
| 무기 분류 | 근접형·원거리형과 확장 가능한 무기 데이터 |
| 무기 스탯 | 공격력·공격속도·사거리·최대 내구도·중량에 따른 이동속도 페널티 |
| 등급 | 무기 종류에 고정된 등급과 스탯 설정 |
| 컨디션 | 스폰 개체별 무작위 공격력 편차 |
| 필드 스폰 | 고정 스폰 포인트에서 무기 종류를 선택해 주기적으로 생성 |
| 필드 조우 | 무기 해금 없이 처음부터 필드 조우 대상에 포함 |

- 분류·스탯·등급·컨디션의 규칙은 [GDD 5장](GDD.md#5-무기-규칙)을 따른다.

---

### 3.2 획득·장착·내구도

| 기능 | 포함 내용 |
|---|---|
| 획득·교체·드롭 | 상호작용 버튼 하나와 장착 슬롯 1개 |
| 교체 처리 | 기존 무기를 플레이어 현재 위치에 드롭한 뒤 새 무기 장착 |
| 장착 상태 | 맨손·무기 장착 전환과 맨손 기본 공격 |
| 근접 내구도 | 한 공격에서 한 번 이상 명중하면 총 1 소모 |
| 원거리 내구도 | 명중 여부와 무관하게 발사 시 1 소모 |
| 무기 파괴 | 내구도 0이면 소멸하고 맨손으로 전환 |
| 공통 장착 | 플레이어·적의 무기 슬롯·장착·교체·드롭 경로 공유 |

- 문맥별 상호작용과 소모 규칙은 [GDD 5.3·5.4](GDD.md#53-내구도-소모-규칙)를 따른다.

---

### 3.3 공격·피해 판정

<a id="5-전투"></a>

| 기능 | 포함 내용 |
|---|---|
| 근접 공격 | 활성 타격 구간의 손·무기 판정과 여러 대상 명중 |
| 근접 중복 제한 | 같은 대상은 공격당 최대 1회 피해 |
| 원거리 공격 | 투사체 생성·이동·충돌과 최초 명중 대상 피해 후 소멸 |
| 공격 간격 | 공격속도 기반 쿨다운과 모션 종료 조건 |
| 피해 적용 | 플레이어 공격에서 적 체력으로 피해 전달 |
| 공통 공격 실행 | 플레이어·적의 무기 공격 실행을 공유하고 플레이어 입력·기록과 분리 |

- 플레이어 공격 판정은 [GDD 6.4](GDD.md#64-플레이어-공격-판정), 적 공격은 2.2를 따른다.

---

### 4.2 XP·레벨업·증강

<a id="8-xp레벨업증강"></a>

| 기능 | 포함 내용 |
|---|---|
| XP 지급 | 적 사망 즉시 정해진 XP 가산, 별도 XP 오브젝트 없음 |
| 레벨업 | XP 누적·레벨업 판정과 최대 체력 회복 |
| 증강 후보 | 최대 레벨 미도달 증강으로 후보 구성과 동일 확률 추출 |
| 증강 선택 | 최대 3개 중 1개 선택, 후보 부족 시 남은 후보 표시·없으면 선택 생략 |
| 선택 중 정지 | 팝업 표시 중 일시정지와 선택 후 진행 재개 |
| 증강 성장 | 재선택 시 레벨 증가와 증강별 최대 레벨·효과 정의 |
| 효과 적용 | 공격력·공격속도·이동속도·최대 체력의 전역 스탯 적용 |
| 무기 특화 증강 | 기존 후순위 범위 유지, 세부 규칙 미정 |

- 선택·성장 규칙은 [GDD 7.1](GDD.md#71-런-내-성장과-기록)을 따른다.
