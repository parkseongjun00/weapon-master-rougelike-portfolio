# 웨폰마스터 로그라이크(가제) 시스템/기능 목록 v0.14
- 기반 문서: `Docs/GDD.md` v0.29
- 역할: 개발해야 하는 시스템과 그에 포함되는 기능을 빠짐없이 나열하는 문서. **우선순위/단계 구분은 여기서 다루지 않는다**. 순서와 일정은 `Docs/DevPlan.md`에서 별도로 다룬다.

---

## 1. 플레이어 이동/조작

- WASD 이동
- 마우스 방향 조준(캐릭터 회전)
- 조준 벡터 추상화 (PC 마우스 / 모바일 스틱을 하나의 값으로 처리)
- Input System 액션맵 구성 (PC/모바일 바인딩 분리)
- 모바일 트윈스틱 입력 (이동 스틱 + 조준 스틱)

## 2. 레벨/아레나

- 아레나 바닥(사각형 또는 원형의 열린 평면)
- 경계 처리(보이지 않는 벽)

## 3. 카메라

- 쿼터뷰 각도/거리 세팅
- 플레이어 추적(트래킹)

---

## 4. 무기 시스템

- 무기 스탯
	- 공격력
	- 공격속도
	- 사거리
	- 최대 내구도
	- 이동속도 페널티
	- 등급/희귀도
	- 컨디션
- 분류: 근접형 / 원거리형(확장 가능한 데이터 구조)
- 필드 스폰: 고정 스폰 포인트에서 주기적으로 리스폰
- 픽업: 자동, 슬롯 1개
- 무기 교체(2단계 순차 처리)
	- ① 기존 장착 무기를 플레이어 현재 위치에 자동 드랍
	- ② 새 무기 장착
- 수동 드랍 버튼
- 장착 상태 관리: 맨손 ↔ 장착
- 내구도 소모
	- 근접=명중 시
	- 원거리=발사 시
- 파괴 처리: 내구도 0 → 소멸 → 맨손 전환
- 맨손 기본 공격(완전 무력화 방지용)

---

## 5. 전투

- 근접 공격 판정
	- 사거리/히트박스 판정
	- 공격속도 기반 쿨다운
	- 범위 내 모든 적 동시 타격(다중 히트)
- 원거리 공격
	- 투사체 생성·이동·충돌 판정
	- 쿨다운
	- 최초 명중 대상에만 데미지 후 소멸(피어싱 없음)
- 데미지 적용 로직(플레이어 → 적)
- 피격 시각 피드백
	- 적/플레이어 공통
	- 피격 순간 반짝임 효과
	- 데미지 수치(정수) 팝업 표시

---

## 6. 적 시스템

- 적 프리팹
- 추적 이동 AI + Boids 알고리즘(separation 규칙) 기반 개체 간 간격 유지
- 접촉 시 플레이어 데미지: 접촉 유지 중 일정 쿨다운마다 반복 데미지(1회성 아님)
- 적 체력/사망 처리
	- 사망 즉시 사전 정의된 XP 값을 플레이어에게 가산(오브젝트 스폰 없음)
- 스폰 로직
	- 아레나 경계 부근, 플레이어로부터 일정 거리 이상 떨어진 지점에서 무작위 스폰
	- 시간 경과에 따른 스폰 수/주기 강도 증가
- 적 유형 다양화
