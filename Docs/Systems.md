## 1. 플레이어 이동/조작

- WASD 이동
- 마우스 방향 조준(캐릭터 회전)
- 조준 방향 전달을 입력 읽기와 분리
- Input System 액션맵 구성

---

## 2. 맵/공간 구조

- 맵별 공간 구조 선택
	- 제한형: 고정된 플레이 공간과 이동 경계
	- 무한형: 플레이어 이동에 따른 공간 생성·재활용과 활성 범위 관리
- 첫 번째 맵의 제한형 공간과 경계 처리
	- 가상 한국 먹자골목·상가 거리의 플레이 공간과 통행 제외 영역(GDD 3장)
	- 건물·점포와 거리 환경 리소스([첫 맵 기준](Art/FirstMap.md) 참고)

---

## 3. 카메라

- 쿼터뷰 각도/거리 세팅
- 플레이어 추적(트래킹)
- 장애물 보정 근접 정도에 따른 주시 높이0~1.5 선형 보간(개발 노트3.29, 사용자 직접 확인3.30)
- 마우스 휠 FOV 줌(기본45도, 범위30~60도)
- 건물 충돌·상체 기준점 시야 가림 시 캐릭터 방향으로 거리 축소·이탈 후 복원
	- 전신·주변 전투 공간의 상시 노출은 보장하지 않는다.

---

## 4. 무기 시스템

- 무기 스탯
	- 공격력
	- 공격속도
	- 사거리
	- 최대 내구도
	- 이동속도 페널티
	- 등급/희귀도
	- 컨디션
- 분류: 근접형 / 원거리형(확장 가능한 데이터 구조)
- 필드 스폰: 고정 스폰 포인트에서 주기적으로 리스폰
- 픽업: 상호작용 버튼, 슬롯 1개
- 무기 교체(2단계 순차 처리)
	- ① 기존 장착 무기를 플레이어 현재 위치에 드랍
	- ② 새 무기 장착
- 상호작용 버튼 하나로 장착/교체/드랍 겸용
- 장착 상태 관리: 맨손 ↔ 장착
- 내구도 소모
	- 근접=명중 시
	- 원거리=발사 시
- 파괴 처리: 내구도 0 → 소멸 → 맨손 전환
- 맨손 기본 공격(완전 무력화 방지용)
- 플레이어·적 공통 무기 슬롯·장착/교체/드롭·공격 실행과 플레이어 입력/기록 분리

## 5. 전투

- 근접 공격 판정
	- 사거리/히트박스 판정
	- 공격속도 기반 쿨다운
	- 활성 타격 구간의 Collider 접촉으로 여러 대상에게 공격당 1회 피해
- 원거리 공격
	- 투사체 생성·이동·충돌 판정
	- 쿨다운
	- 최초 명중 대상에만 데미지 후 소멸(피어싱 없음)
- 데미지 적용 로직(플레이어 → 적)
- 피격 시각 피드백
	- 적/플레이어 공통
	- 피격 순간 반짝임 효과
	- 데미지 수치(정수) 팝업 표시

## 6. 적 시스템

- 적 프리팹
	- 정체성·공통 표현·개별 디자인의 검토 상태: [적 디자인 문서](Art/EnemyDesign.md)
- 몸체 크기 기반 대상별 다중 링 자동 계산·예약·포위·안쪽 충원·상한 초과 대기와 목표·도착 상태 관리
- NavMesh 경로 추종·장애물 우회·Agent 간 회피와 안전한 생성 위치 검사
- 유형별 공격과 플레이어 피해 판정(GDD 6.1)
	- 기본 적 펀치·공통 모션/주먹 판정 적용. 사용자 타격 확인과 세부 회귀 범위를 구분
	- 공격 시작·예고·유효 시점·범위·방향 확정·빗나감·회복 처리
	- 공격 상태와 피해 판정에 맞춘 애니메이션 연결
	- 사망·비활성화·풀 재사용 시 공격 상태 정리
- 적 체력/사망 처리
	- 사망 즉시 사전 정의된 XP 값을 플레이어에게 가산(오브젝트 스폰 없음)
- 스폰 로직
	- 제한형: 맵 경계 부근에서 플레이어와 일정 거리 이상 떨어진 지점에 무작위 스폰
	- 무한형: 플레이어 주변 활성 범위에서 일정 거리 이상 떨어진 지점에 무작위 스폰
	- 시간 경과에 따른 스폰 수/주기 강도 증가
- 적 유형 다양화
