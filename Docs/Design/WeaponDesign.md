게임 공통 무기의 디자인 방향·공격 방식·후보를 정리한다. 획득·교체·내구도·피해 판정과 조작 규칙은 [GDD 5장·6장](../GDD.md)을 따른다. 사용자 확인 사항과 Codex 제안은 상태를 구분한다.

## 1. 디자인 방향

| 구분 | 방향 | 상태 |
|---|---|---|
| 게임 콘셉트 | 주변의 무기와 무기로 쓰는 물건을 확보·교체하는 즉흥 전투 | GDD 기준 |
| 다양화 | 물건의 외형뿐 아니라 공격 메커니즘의 차이를 확대 | 사용자 방향 |
| 선정 단위 | 물건 이름을 나열하기 전에 공격 방식별 종류를 비교 | 사용자 방향 |
| 선호 범위 | 근접 타격·직사 발사·곡사 투척·산탄 발사·지속 분사·왕복 투척 | 사용자 선호, 최종 제작 목록 미정 |
| 별도 검토 | 장판 생성·함정 설치·자동 공격 장치 | 선호 범위와 구분해 검토 |
| 제외 | 방어·반격류 | 사용자 결정 |

- 여러 종류를 비교해 선정하며, 실제 적용과 확인은 순차적으로 진행한다.
- 모든 무기에 별도 공격 기능을 요구하지 않고 기존 방식의 수치·형상·모션 차이도 비교한다.
- 예시에 적힌 물건은 메커니즘 설명용이며, 모델 제작·프리팹 추가·게임 규칙 변경의 확정 목록이 아니다.

## 2. 무기 구성

### 2.1 공격 수행 방식에 따른 구분

| 묶음 | 구분 기준 | 포함 후보 | 상태 |
|---|---|---|---|
| 직접 공격형(가칭) | 무기를 겨누고 휘두르거나 발사해 적에게 공격을 전달 | 근접·직사·곡사·산탄·지속 분사·왕복 | 묶음은 사용자 선호를 반영, 명칭·정의는 Codex 제안 |
| 영역 제어·설치형(가칭) | 효과·장치가 작동할 위치를 정하고 적을 그 영향 안에 두도록 운용 | 장판·함정·자동 공격 장치 | 묶음은 사용자 구분을 반영, 명칭·정의는 Codex 제안 |

- 두 묶음은 공격 수행 방식에 대한 기획 구분이며, 코드의 대분류나 제작 난이도 등급을 뜻하지 않는다.
- 근접·원거리는 거리 기준이고 투척·분사·설치는 사용 방식 기준이므로 같은 무기에 함께 적용될 수 있다.
- 같은 투척물도 직접 명중이 중심인지, 지속 영역을 남기는 것이 중심인지에 따라 역할이 달라진다.
- Area Denial은 영역 제어, Deployables는 설치·전개 장치의 용어로 참고한다. 위 두 묶음 전체가 보편적인 공식 분류라는 의미는 아니다.
- [Blizzard의 토르비욘 설명](https://overwatch.blizzard.com/pt-br/news/22639849/os-damos-la-bienvenida-a-la-temporada-13-de-partidas-competitivas/)은 자동 공격 포탑의 Deploy Turret과 지속 피해 구역의 Area Denial을 구분한 참고 사례다.

---

### 2.2 종류와 개별 무기의 관계

- 공격 방식별 역할을 먼저 비교하고, 개별 물건의 형태·사용 동작·수치를 정한다.
- 하나의 공격 방식으로 여러 무기를 만들거나, 투척 후 장판 생성처럼 여러 방식을 결합할 수 있다.
- 종류의 개수와 실제 제작할 무기의 개수는 구분한다.
- 종류별 예시와 특징은 3장에서 관리하고, 개별 제작 대상이 정해지면 4장에 반영한다.

## 3. 공격 방식

### 3.1 종류별 비교

| 종류 | 예시 | 플레이 특징·약점 | 상태 |
|---|---|---|---|
| 근접 타격류 | 방망이·쇠파이프·칼 | 접근과 타격 시점 판단, 접근 위험 | 기존 공격 방식, 사용자 선호 |
| 직사 발사류 | 권총·소총 | 직접 조준, 앞의 적이 뒤의 적을 가림 | 기존 공격 방식, 사용자 선호 |
| 곡사 투척류 | 돌멩이·수류탄 | 도착 위치 예측, 비행 시간으로 인한 빗나감 | 사용자 선호, 추가 후보 |
| 산탄 발사류 | 샷건 | 근거리 화력 집중, 원거리 탄 분산 | 사용자 선호, 추가 후보 |
| 지속 분사류 | 소화기·화염방사기 | 방향을 유지·이동하며 지속 명중, 짧은 거리·자원 소모 | 사용자 선호, 추가 후보 |
| 왕복 투척류 | 부메랑·회수형 원반 | 복귀 궤적 조정, 회수까지 재공격 제약 | 사용자 선호, 추가 후보 |
| 장판 생성류 | 화염병·독성병(지속 피해 구역) | 공격 후에도 영역 유지, 영역 이탈 시 효율 감소 | 별도 검토 후보 |
| 함정 설치류 | 지뢰·덫 | 사전 배치와 유인, 즉시 대응에 불리 | 별도 검토 후보 |
| 자동 공격 장치류 | 고정형 자동 포탑 | 설치 위치 판단, 직접 조준 비중 감소 | 별도 검토 후보 |

- 특징·약점은 비교를 위한 설계 제안이며, 공격 규칙과 수치는 미확정이다.
- 장판은 구역에 머무는 동안 지속 작용하고, 함정은 감지 조건을 충족하면 발동하는 방향으로 구분한다.
- 돌멩이의 단일 충돌과 수류탄의 폭발처럼 같은 종류 안에서도 명중 효과가 달라질 수 있다.

---

### 3.2 추가 특성

| 특성 | 구분할 내용 | 상태 |
|---|---|---|
| 충전 | 공격 준비 시간과 발사·타격 시점 | Codex 검토 제안 |
| 관통 | 명중 후 진행과 여러 대상 피격 | Codex 검토 제안 |
| 유도 | 발사 후 방향 보정과 대상 선택 | Codex 검토 제안 |
| 도탄 | 명중·충돌 후 튕김과 후속 피격 | Codex 검토 제안 |

- 여러 종류에 붙일 수 있는 변형으로 검토하며, 각각을 독립적인 무기 종류로 확정하지 않는다.
- 현재 피해 판정은 [GDD 6.4](../GDD.md#64-데미지-판정-방식)를 따른다. 관통 등 추가 특성은 개별 규칙을 정한 뒤 반영한다.

## 4. 적용 대상

| 대상 | 현재 기반 | 상세 기록 |
|---|---|---|
| 기존 근접·직사 | 근접 타격과 직선 단발 투사체 | [공통 무기 실행과 모션](../DevNotes/03-PlayerAnimation.md#331-플레이어적의-무기-실행과-사람형-모션-공유) |
| 무기 데이터·등록 | 프리팹 내장 데이터와 로스터 기반 등록 | [프리팹 중심 데이터·스폰 등록](../DevNotes/03-PlayerAnimation.md#317-무기-데이터와-스폰-등록의-프리팹-중심-통합) |
| 추가 무기 | 종류별 물건·리소스·공격 규칙 | 미선정 |

- 기존 구현은 새 후보의 적용 완료를 뜻하지 않는다. 획득·사용·드롭·재획득·파괴의 전체 사용자 플레이 확인은 남아 있다.
- 구현 경로·자산 경로·적용 결과는 개발 노트에서 관리하고, 본 문서는 디자인 방향과 후보를 관리한다.

## 5. 검토 사항

| 범위 | 정할 내용 |
|---|---|
| 분류 | 두 묶음의 최종 명칭·기준과 혼합형 무기의 구분 |
| 제작 목록 | 이번에 추가할 종류와 개별 물건·수량 |
| 개별 성격 | 유효 거리·범위·공격 속도·빈틈·내구도와 기존 무기 대비 차이 |
| 곡사 투척 | 투척 거리 조절·궤도·장애물 충돌·착탄 효과 |
| 산탄 | 퍼짐·동일 대상의 여러 탄 피격·발사당 내구도 |
| 지속 분사 | 공격 유지·종료·피해 주기·내구도 소모 단위 |
| 왕복 투척 | 회수 대기·복귀 경로와 교체·드롭·파괴 중 처리 |
| 장판·함정·장치 | 지속 시간·발동 조건·대상 선택·중첩·동시 존재 수·무기 교체 후 유지 |
| 외형·제작 | 물건별 모델·장착 자세·공격 모션·효과와 리소스 예산 |

- 공통 획득·교체·내구도 규칙은 [GDD 5장](../GDD.md#5-무기-시스템-명세)에서 확인하고, 새 방식에 필요한 변경 범위를 개별적으로 정한다.
- 후보의 타당성과 제작 범위는 함께 검토하며, 최종 반영 목록과 구현 방식은 미확정이다.
