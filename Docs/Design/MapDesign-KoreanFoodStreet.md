## 1. 디자인 방향

<a id="1-장소의-정체성"></a>

| 구분 | 기준 |
|---|---|
| 장소 | 현실적으로 있을 법한 가상의 현대 한국 먹자골목·상가 거리 |
| 참고 | 방이맛골의 거리·상가 관계. 측량 재현이나 실존 건물·상호 복제가 목적은 아님 |
| 인상 | 친숙한 상권, 관리된 상가와 개성 있는 점포. 연식 있는 건물과 새로 정비한 점포 전면의 공존 |
| 현실성 | 건물 외곽선·층별 연결·점포 구획·출입구와 외벽의 관계. 사진 같은 재질은 필수 조건이 아님 |
| 확장 범위 | 한국 상가 거리는 첫 스테이지. 게임 전체의 장소를 한정하지 않음 |

- 현장 무기 확보·교체는 GDD의 게임 공통 콘셉트다. 적의 정체성·표현 후보는 [적 디자인](EnemyDesign.md)을 참고한다.
- 콘셉트와 공간 구성 원칙은 사용자 확인 사항이며, 배치안 수치·개별 리소스의 상태와 구분한다.

## 2. 공간 구성

<a id="2-공간-구성과-규모"></a>

### 2.1 공간과 통행

<a id="21-확정된-구성-원칙"></a>

- 외곽 160×160m인 제한형 맵이다.
- 넓은 주 거리·교차로가 주요 전투 공간이며 짧은 지선·코너의 열린 공간은 보조 공간이다.
- 격자형 가로·세로 길을 허용하고 교차로의 바닥·통행 영역을 자연스럽게 연결한다.
- 건물 내부·블록 안쪽 필지·건물 사이 틈은 현재 플레이 공간이 아니다. 후면 작업 공간이라는 설정도 통행 허용을 뜻하지 않는다.
- 공사 구역·새로운 상호작용 요소는 현재 환경 제작 범위에서 제외한다.

---

### 2.2 배치안 수치

<a id="22-현재-배치안의-수치"></a>

| 항목 | 현재 배치안 | 취급 |
|---|---|---|
| 동서 주 거리 | 18m | 보행 여유부를 포함한 전체 거리 폭 |
| 남북 교차 상업로 | 16m | 보행 여유부를 포함한 전체 거리 폭 |
| 남동 짧은 지선 | 14m | 보행 여유부를 포함한 전체 거리 폭 |
| 건물·1층 점포 | 건물 24개·점포 23개 | 현재 구성. 영구적인 콘텐츠 수량 목표는 아님 |

- 거리 폭은 배치 검증 중인 수치이며 차도 폭만을 뜻하지 않는다.
- 코너 전면 공지는 건물을 교차로에서 물려 확보한 앞마당이다. 별도 실내·상호작용 시설이 아니다.
- 하역 포켓·정류장 여유부는 공간의 용도 구분이다. 소품 배치나 기능까지 확정한 것은 아니다.

---

### 2.3 블록별 성격

<a id="3-블록별-성격"></a>

| 블록 | 방향 | 층수 중심 | 표현 방향 |
|---|---|---|---|
| 북서(NW) | 오래된 식당가 | 2~4층 | 오래된 음식점 건물군과 축적된 상가 외관 |
| 북동(NE) | 비교적 정돈된 상가 | 3~5층 | 정돈된 건물과 점포 전면 |
| 남서(SW) | 낮은 상가와 작업·후면 공간 | 2~4층 | 저층 상점과 업무·창고·작업 용도의 후면 |
| 남동(SE) | 야간 상권과 숙박업 | 4~6층 | 음식점·주점과 상층 노래방·숙박 용도 |

- 같은 동네 안에서 연식·높이·외관·용도가 달라지는 정도로 구분한다. 블록마다 다른 아트 스타일을 적용하지 않는다.
- 야간 상권은 업종 성격이며 맵 시간대를 밤으로 확정한 것이 아니다. 그레이박스의 블록 색상은 구분용이다.

## 3. 표현 기준

### 3.1 건물과 점포

<a id="4-건물과-점포의-관계"></a>

| 대상 | 기준 |
|---|---|
| 건물 몸체 | 외곽선과 소속 점포를 읽을 수 있게 구성. 1층과 상층은 같은 몸체로 연결 |
| 점포 구획 | 소속 건물의 1층 전면 안에서 구획하고 이웃 건물에 걸치지 않게 구성 |
| 후면 필지 | 개별 건물과 닫힌 후면으로 표현. 연결된 거대 고밀도 구조물이 목표는 아님 |
| 측면·후면 | 도로·열린 공간에 노출되는 면도 건물 용도에 맞게 구성. 전면에만 창문이 집중된 초기 표현은 제작 시 검토 |
| 창문 | 인접 벽·계단실·후면 용도에 맞춰 판단하며 모든 면의 동일 반복은 요구하지 않음 |

- 현재 국밥집은 SW02, 포차는 SW03 소속이다. 이름은 업종 표기이며 실존 상호가 아니다.
- 여러 건물을 받치는 공통 1층 덩어리에 상층을 임의로 쌓는 방식은 기본 구성으로 삼지 않는다.

---

### 3.2 외관 제작

<a id="71-사용자-확인-제작-방향"></a>

- 배치와 그레이박스 치수를 출발점으로 단순 도형 조립·메시 생성 방식으로 제작한다.
- 건물 몸체·점포 전면을 기반으로 외벽 재질·창틀·유리·차양·간판을 교체·조정한다.
- 간판은 판 앞면의 이미지·색을 교체하는 방식이며 구체적인 상호·그래픽은 검토 사항이다.
- 설비·소품은 필요한 대상을 별도 제작·생성해 건물과 결합한 결과를 확인한다.

---

### 3.3 시야와 카메라

<a id="6-카메라-정책과-후속-과제"></a>

- 월드 기준 쿼터뷰를 사용한다. 건물이 상체 기준점을 가리면 카메라가 캐릭터 쪽으로 당겨져 시야 확보를 시도한다.
- 전신과 주변 전투 공간의 상시 노출은 보장하지 않는다. 환경 제작만을 이유로 건물 높이를 일괄 축소하지 않는다.
- 충돌·시야 보정과 주시 높이의 수치·검증은 [카메라 개발 노트](../DevNotes/03-PlayerAnimation.md#327-deoccluder로-낮은-건물의-시야-가림-대응)와 [주시 높이 조절](../DevNotes/03-PlayerAnimation.md#329-카메라-근접-정도에-따른-주시-높이-선형-보간)을 따른다.
- 건물 불투명도 조절·추가 감쇠는 [자동 카메라 접근과 건물 페이드](../Backlog.md#camera-fade-and-damping)의 검토 대상이다.

## 4. 적용 대상

<a id="7-제작-착수-시-확인할-사항"></a>

### 4.1 배치 자료

<a id="5-배치도와-그레이박스의-관계"></a>

| 자료 | 역할 |
|---|---|
| [배치도 HTML](../../Design/Arena/arena-food-street-concept.html) | 건물별 위치·크기·층수·점포 소속과 통행 영역 |
| Assets/Scenes/GameScene.unity | 실제 배치·충돌·카메라·플레이 상태 |
| 그레이박스 | 공간 규모와 건물·거리 관계의 비교. 외관 디테일의 최종 시안과 구분 |

- 배치도는 북서 모서리 기준이며 Unity 지면 좌표는 `X = x - 80`, `Z = 80 - y`로 변환한다.
- 씬을 확인할 때 BangiGraybox_160m의 활성 구성과 이전 구성을 구분한다. 배치도와 씬의 차이는 확인 없이 어느 한쪽에 맞추지 않는다.
- 개별 씬 관찰을 전체 전투·스폰·이동이나 최종 배치의 합격으로 확대하지 않는다.

## 5. 검토 사항

<a id="73-다음-실행의-경계와-미확정-항목"></a>

<a id="23-플레이-스케일-참고값"></a>

| 범위 | 미정·확인할 내용 |
|---|---|
| 전체 표현 | 최종 아트 스타일·팔레트·조명·시간대·세계관 사건 |
| 개별 요소 | 간판 디자인·소품 구성·재사용할 건물과 부품의 종류·수량 |
| 제작 규모 | 재질·텍스처·폴리곤 예산 |
| 수용 기준 | 최종 배치·실제 인게임 외관의 합격 조건과 시험 범위 |

- **스케일 참고값**

	| 항목 | 참고값 | 취급 |
	|---|---|---|
	| 캐릭터 높이 | 약 2m | 현재 모델과 씬에서 확인 |
	| 기본 이동 속도 | 6m/s | 당시 PlayerMovement 기본값·씬 설정·런타임 배율 구분 |
	| 카메라 지면 표시 범위 | 약 32×17m | 설정·화면 비율·측정 위치에 따라 재확인 |

	- 공간 비교용 참고값이며 카메라·플레이어를 맞추기 위한 고정 목표가 아니다. 배치도의 카메라 사각형·이동 반경도 실제 화면이나 장애물 우회 경로를 보장하지 않는다.
