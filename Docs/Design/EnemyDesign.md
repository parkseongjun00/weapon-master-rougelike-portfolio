## 1. 디자인 방향

<a id="2-참고-자료의-활용-기준"></a>

<a id="1-공통-방향"></a>

| 구분 | 내용 | 상태 |
|---|---|---|
| 적용 범위 | 여러 장소의 스테이지에서 사용할 적. 한국 먹자골목에만 한정하지 않음 | 사용자 확인 |
| 정체성 | 사람형 거리 싸움꾼·건달 패거리 | 사용자 논의 후보 |
| 검토 사유 | 돌발적인 싸움에서 주변 물건으로 대응하는 상황과 연결 | 사람형 후보의 검토 근거 |
| 집단의 관계 | 개성과 구성원 관계를 스토리텔링에 활용 | 검토 가능성 |

- **참고**

	| 출처 | 참고할 인상 | 구분 |
	|---|---|---|
	| 사용자 | "짱구는 못말려" 극장판에 등장할 법한 개성 있는 패거리 | 참고 방향 |
	| Codex | 자신들은 진지하지만 관객에게는 우스운 허세, 유난스러운 복장·조직 문화, 구성원의 티격태격 | 해석·검토 후보 |

	- 개별 디자인에서 가져올 특징을 명시한다. 참고 작품의 캐릭터·복장·문양 자체를 제작 기준으로 삼지 않는다.
	- 작품별 집단의 정확한 명칭과 설정을 검증한 기록은 아니다.

## 2. 적 구성

| 구분 | 구성 방향 | 상태 |
|---|---|---|
| 현재 대표 적 | Enemy_Grunt_01을 사용하는 단일 범용 적 | 적용 모델 |
| 유형 구분 | 기존 모델을 재사용하면서 공격 유형별 표현을 구분. 신규 모델은 필수 조건이 아님 | 표현 검토 기준 |
| 후속 유형 | 원거리 견제형·현장 무기 활용형 우선 검토 | 사용자 방향, 무기 준비 후 재개 |
| 집단 구성 | 종별·조직·대장과 구성원의 관계 | 미정 |

- 공격 유형·피해 조건은 [GDD 6.1](../GDD.md#61-적-유형)이 기준이다. 기존 슬라임·로봇 탐색과 테스트 리소스는 현재 적 콘셉트의 확정을 뜻하지 않는다.

## 3. 표현 기준

### 3.1 외형

<a id="3-외형과-가독성"></a>

| 기준 | 확인할 내용 |
|---|---|
| 개체 구분 | 쿼터뷰에서 플레이어와 적이 구분되는가 |
| 물건 구분 | 적의 몸체와 손에 든 물건이 구분되는가 |
| 역할 구분 | 다수가 표시돼도 체형·자세·색 배치로 역할을 읽을 수 있는가 |
| 장소 확장 | 다른 스테이지에서도 선택한 적 콘셉트를 연결할 수 있는가 |

- 체격·헤어스타일·유난스러운 복장·포즈를 구분 수단으로 사용하는 것은 Codex 후보이며 미확정이다.

---

### 3.2 동작과 연출

<a id="4-행동과-연출"></a>

- 접근·공격·피격 동작은 선택한 적 콘셉트와 피해 규칙에 맞춰 표현한다.
- 공격의 예고·유효 시점·회복 상태를 게임 시점에서 구분할 수 있게 한다.
- 과장된 휘청거림·넘어짐, 허세 섞인 대사, 기절·리타이어로 읽히는 퇴장은 Codex 후보이며 미확정이다.
- 퇴장 표현과 HP·XP·제거 등 게임 규칙은 구분한다. 공격 거리·주기·판정·AI 규칙은 GDD에서 관리한다.

## 4. 적용 대상

<a id="5-대표-적-검토"></a>

| 대상 | 표현 기반 | 상세 기록 |
|---|---|---|
| Enemy_Grunt_01 | 사용자 지정 모델, 대기·달리기, 기존 사람형 펀치, 선택 퇴장 연결 | [적 애니메이션 개발 노트](../DevNotes/05-EnemyAnimation.md) |
| 기본 펀치 | 기존 모션의 준비·타격·공격 후 구간 활용. 별도 예고 모션 제작은 추가 판단 대상 | [기본 적 펀치](../DevNotes/05-EnemyAnimation.md#533-공통-무기모션과-기본-적-펀치) |

- 기본 적 펀치의 사용자 확인과 개별 검증 범위는 개발 노트에 보존한다. 현재 모델 적용은 전체 적의 정체성·조직·분위기가 확정됐다는 의미가 아니다.
- 대표 디자인에서는 정체성 한 문장, 실루엣·복장·체형과 접근·공격·피격·퇴장 표현을 검토한다. 판단 기준은 캐릭터 성격·전투 가독성·게임 콘셉트·기존 규칙과의 연결이다.

## 5. 검토 사항

<a id="6-후속-후보와-열린-질문"></a>

- **미정 사항**

	| 범위 | 미정 내용 |
	|---|---|
	| 집단·서사 | 조직명·목적·규칙, 대장과 구성원의 관계, 싸움이 발생하는 사건 |
	| 외형 | 신체 비율·치비 여부·의상·문양·색상·얼굴 표현 |
	| 연출 | 출혈·피격 효과음·총기의 사실성·사망과 퇴장 표현 |
	| 제작 규모 | 모델·재질·텍스처 예산 |
	| 게임 공통 설정 | 정식 타이틀과 '야차'의 세계관 내 의미. '야차 시뮬레이터'는 후보 표현 |

- **후속 후보**

	| 후보 | 출처·현재 판단 |
	|---|---|
	| 투척 건달 | Codex 추천 후보. 첫 원거리 적의 물건·동작은 미정 |
	| 새총·폭죽·개조 발사기 | 대안 후보. 분위기·가독성·제작 비용 비교 |
	| 성급한 적·덩치 큰 적·거리 유지 적 | 역할 후보. 유형 확장 시 규칙과 디자인을 함께 검토 |
	| 직선 돌진형 | 서사적 당위성·연출 적합성 우려로 우선순위 낮음 |
	| 추가 장소의 적 | 장소·수량과 공통 정체성의 변형 범위 미정 |

	- 사용자 방향은 무기 추가·역할 구분 선행과 적 유형 확장 유보다. 원거리 공격·현장 물건 활용의 기능 과제는 [백로그](../Backlog.md#enemy-ranged-and-pickup)를 따른다.
	- [협동·진형 전술](../Backlog.md#enemy-group-tactics)은 장기 구상이며 집단의 조직 설정과 구분한다. [적 간 공격 유도·반응 말풍선](../Backlog.md#enemy-friendly-fire-and-bubbles)의 피해·경직·표시 규칙은 미정이다.
