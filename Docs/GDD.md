## 1. 개요

| 항목          | 내용                                     |
| ----------- | -------------------------------------- |
| 장르          | 로그라이트 (엔드리스 웨이브 서바이벌)                  |
| 시점          | 3D 쿼터뷰                                 |
| 조작 | 키보드 이동·마우스 조준·공격·상호작용 |
| 개발 환경       | Unity, 신규 Input System 사용              |
| 콘셉트 | 다양한 장소에서 주변의 무기와 무기로 쓰는 물건을 확보·교체하며 살아남는 즉흥 전투 |
| 세계관/타이틀/비주얼 | 적 콘셉트·사건·조직 설정·타이틀·비주얼 분위기는 별도 검토 |

- 플레이어는 현장에서 확보할 수 있는 싸울 수단을 바탕으로 다음 행동을 판단한다.
- 무기를 다루는 능숙함은 상황에 맞는 확보·사용·교체 판단으로 드러난다.
- 게임은 장소별 스테이지 확장을 지향한다. 한국 먹자골목은 첫 번째 스테이지이며 다른 장소의 구성과 수량은 미확정이다.
- '손에 잡히는 것이 무기가 된다'는 콘셉트는 무기로 지정한 물건의 획득·사용으로 구현한다. 모든 배경 오브젝트의 집기·투척·파괴는 별도 기능 검토 대상이다.
- 소개 방향은 장소와 돌발 상황을 먼저 제시해 플레이어가 자신의 행동을 상상하게 하는 것이다. 유입·공유 효과는 검증 과제다.

## 2. 디자인 목표

1. **급박한 상황에서의 즉흥 판단**: 정해진 최적 루트가 없고, 상황(적 구성, 남은 내구도, 주변 무기 배치)에 따라 매 순간 판단해야 한다.
2. **전투 메커니즘의 신속한 전환**: 근접↔원거리처럼 완전히 다른 조작감의 무기를 자주 갈아타야 한다.
3. **캐주얼함**: 판과 판 사이의 영향력을 최소화한다. 한 판 한 판이 무겁게 이어지지 않고 가볍게 즐길 수 있어야 한다.

## 3. 런(Run) 구조

- **엔드리스 웨이브 서바이벌**
	- 선택한 맵에서 시간이 지날수록 출현 빈도가 높아지는 적 웨이브를 상대한다.
	- **클리어(승리) 조건은 없다**.
	- 런은 플레이어 사망으로만 종료된다.
	- 런의 목표/성과 지표: **최대한 오래 생존** 또는 **최대한 많은 적 처치**.
		- 두 지표를 함께 기록.

- **맵 공간 구조**
	- 맵마다 제한형 또는 무한형 공간 구조를 선택한다.
	- 제한형 맵은 건물, 지형 또는 보이지 않는 벽으로 이동 범위를 제한한다.
	- 무한형 맵은 플레이어의 이동에 맞춰 공간이 계속 이어진다.
	- 첫 번째 맵은 핵심 전투와 공간 밀도를 먼저 검증하고 초기 제작 범위를 통제하기 위해 제한형으로 제작한다.
	- 첫 번째 맵은 전체 외곽 160×160m인 가상의 한국 먹자골목·상가 거리다.
	- 첫 번째 맵의 주요 전투 공간은 넓은 주 거리와 교차로이며, 짧은 지선과 코너 공간은 보조 공간이다. 건물 내부와 블록 안쪽 필지는 현재 플레이 공간이 아니다.
	- 무한형 맵은 포스트-MVP 콘텐츠로 검토한다.

## 4. 코어 루프

### 4.1 런 전체 흐름

<a id="41-매크로-루프-런-전체"></a>

```
[런 시작: 맨손 상태로 선택한 맵에 스폰]
   → [진행: 전투·무기 관리·레벨업이 반복되며 난이도가 계속 상승 (반복 주기는 4.2 참고)]
   → [사망: 런 종료. 생존시간·처치수 기록]
[다음 런: 칭호·도감의 기록과 발견을 유지하며 다시 시작]
```

- 칭호는 해당 조건을 달성하면 갱신하고, 무기 도감은 실제 획득 시 발견을 기록한다. 세부 조건은 7.2를 따른다.

---

### 4.2 전투 반복 흐름

<a id="42-마이크로-루프"></a>

1. 런 시작 즉시 맨손 상태로 시작한다.
2. 적이 사방에서 접근하면 이동하며 무기를 확보한다.
3. 장착한 무기로 공격하면 5.3의 규칙에 따라 내구도가 소모된다.
4. 내구도가 임계치에 가까워지면 계속 쓸지, 다른 무기로 갈아탈지, 수동으로 버리고 재정비할지 판단한다.
5. 무기가 파괴되거나(내구도 0) 수동으로 드롭하면 맨손 상태로 전환된다.
6. 적을 처치하면 XP가 누적되고, 레벨업하면 증강을 선택한다.
7. 시간이 지날수록 적의 출현 빈도가 높아지고, 이 흐름이 사망까지 반복된다.

전투 반복 흐름이 플레이의 중심이며, 기록·발견과 세계관은 반복할 동기를 제공한다.

## 5. 무기 규칙

<a id="5-무기-시스템-명세"></a>

### 5.1 분류

| 분류 | 특징 |
|---|---|
| 근접형 | 사거리 짧음 |
| 원거리형 | 사거리 김, 투사체 기반 |

무기별 고유 정체성(빠르고 약한 무기, 느리고 강한 무기 등)은 무기 개체별로 스탯을 직접 정해 부여한다.

근접·원거리 외의 추가 대분류 채택은 미정이다.

---

### 5.2 무기 스탯

| 항목 | 의미 | 적용 규칙 |
|---|---|---|
| 공격력 | 명중 시 가하는 피해 | 무기별 기본값에 증강·컨디션 배율 적용 |
| 공격속도 | 공격 빈도 | 초당 공격 횟수로 표현하며 쿨다운과 구분 |
| 사거리 | 공격이 닿는 거리 | 근접 판정·원거리 투사체 설정에 따라 결정 |
| 최대 내구도 | 사용할 수 있는 횟수 | 소모 규칙은 5.3 참고 |
| 중량 | 장착에 따른 이동속도 감소 | 채택된 후순위 속성 |
| 등급 | 무기 종류에 고정된 희귀도 | 일반·희귀·영웅·전설. 5.5 참고 |
| 컨디션 | 스폰 개체별 공격력 편차 | 공격력에만 적용. 5.6 참고 |

---

### 5.3 내구도 소모 규칙

| 무기    | 내구도 소모 시점 | 비고                    |
| ----- | --------- | --------------------- |
| 근접무기 | 한 공격에서 한 번 이상 명중하면 1 소모 | 여러 적에게 명중해도 총 1 소모, 헛스윙은 소모 없음 |
| 원거리무기 | 발사 시 1 소모 | 명중 여부 무관, 사실상 탄약처럼 작동 |

---

### 5.4 획득·교체·드롭

<a id="54-획득버리기-규칙"></a>

- 시작 상태: **맨손**
- 장착 슬롯: **1개**
- 무기는 고정 스폰 포인트에서 주기적으로 스폰된다.
- **상호작용 버튼 하나**로 장착/교체/드롭을 모두 처리한다.
	- 바닥 무기 범위 안에서 누르면 장착한다. 손에 이미 무기가 있으면 그 무기를 플레이어 현재 위치에 드롭하고 교체하며, 맨손이면 그대로 장착한다.
	- 바닥 무기 범위 밖에서 누르면(손에 무기가 있을 때) 즉시 버리고 맨손이 된다.
	- 둘 다 아니면(맨손 + 범위 밖) 아무 일도 일어나지 않는다.
- 무기 파괴(내구도 0) 시 완전 소멸하고 맨손 상태(약한 기본 공격)로 전환된다.

---

### 5.5 등급(Rarity) 시스템

- 등급은 무기 종류에 고정되며 설계 시점에 정한다. 같은 종류의 무기가 스폰마다 다른 등급으로 나오지 않는다.
- 예를 들어 일반 등급으로 정한 방망이는 항상 일반 등급이다.
- 등급은 일반 → 희귀 → 영웅 → 전설의 네 단계다.
- 등급은 전체 스탯 예산의 가이드다. 공격력·공격속도·최대 내구도의 최종값은 무기 역할에 맞춰 직접 정하거나 외부 밸런싱 도구로 계산해 반영한다.
- 런타임의 등급 공식으로 최종 스탯을 계산하지 않는다. 높은 등급이 모든 상황에서 높은 체감 가치를 보장하지는 않는다.
- 필드에서 무작위인 요소는 조우하는 무기 종류와 개체의 컨디션이다.

---

### 5.6 컨디션(Condition) 시스템

- 컨디션은 같은 종류·등급의 무기에도 스폰 개체별 공격력 편차를 주는 요소다.
- 최대 내구도·공격속도에는 적용하지 않는다. 내구도 편차의 불공평함을 줄이고 개체 상태와 공격속도를 구분하기 위한 범위다.
- 맨손은 컨디션 적용 대상에서 제외한다.

| 컨디션 | 공격력 배율 변화 |
|---|---|
| 매우 나쁨 | -10% |
| 나쁨 | -5% |
| 보통 | 0% |
| 좋음 | +5% |
| 매우 좋음 | +10% |

## 6. 전투·적 규칙

<a id="6-전투적-시스템"></a>

### 6.1 적 행동과 공격 규칙

<a id="61-적-유형"></a>

- 적은 유형별 공격 메커니즘으로 구분한다. 정체성·외형·성격과 공격·피격·퇴장 표현은 디자인 검토 후 확정한다.
- 플레이어 피해는 유형별 공격 조건·유효 시점·범위에 따라 적용한다.

- **체력과 사망**
	- 적은 자체 HP를 가지며 플레이어의 근접·원거리 공격으로 피해를 받는다.
	- HP가 0이 되면 전투 대상에서 즉시 제외된다. XP 지급은 7.1을 따른다.
	- 퇴장 애니메이션이 있으면 이동·공격·피격 판정을 종료한 외형만 재생한 뒤 제거한다. 없으면 외형도 즉시 제거한다.
- **접근과 포위**
	- 대상 주변의 자리를 예약해 여러 방향에서 둘러싼다. 몸체 크기·여유 간격에 따라 원 반경과 자리 수를 정하고 안쪽 원이 차면 바깥 원을 추가한다.
	- 안쪽 자리가 비면 바깥 참여자를 충원한다. 수용량을 넘는 적은 안전 위치에서 대기한다.
	- 자리에 도착하면 정지하고 대상이 이동하면 같은 자리를 재추적한다.
	- 이동 가능한 경로로 장애물을 우회하고 주변 개체를 회피한다. 도달할 수 없는 자리는 재배정한다.
	- 자리는 접근 위치를 정한다. 공격 시작·피해 판정은 유형별 규칙을 따르며 자리 점유 자체가 공격 허가나 동시 공격 수 제한은 아니다.
	- 접촉 보정·최대 원 수·간격의 구체값은 튜닝 대상이다.
- **공격 규칙**
	- 단순한 몸체 접촉은 공통 피해 조건이 아니다. 몸체 충돌을 쓰는 공격도 해당 유형의 활성 상태와 판정 조건에서만 피해를 준다.
	- 유형별로 공격 시작 조건·예고·유효 시점·범위·방향 확정 시점·빗나감·공격 후 빈틈을 정한다.
	- 피해량·공격 간격·동일 공격의 중복 피해 조건도 유형별로 정한다.
	- 몸체 충돌·개체 간 분리와 피해 판정을 구분한다. 공격을 읽고 회피·접근·반격하거나 공격 후 빈틈을 활용할 수 있게 하기 위한 규칙이다.
- **기본 적 펀치**

	| 항목 | 규칙·초기 조정값 |
	|---|---|
	| 시작 | 사거리에서 정지하고 방향을 확정한 뒤 한 손 펀치 |
	| 피해 | 8 |
	| 목표 공격 간격 | 1초 |
	| 시작 거리 | 1.35m |
	| 예고 | 별도 예고 제작 전에는 기존 펀치 준비 구간 사용 |
	| 명중 | 손 타격 구간에 접촉한 플레이어에게 공격당 최대 1회 피해 |
	| 빗나감·종료 | 빗나가도 모션 종료까지 재생 |
	| 재공격 | 모션 종료와 공격 간격 조건을 모두 만족하면 가능 |

- **스폰 위치**
	- 제한형 맵은 경계 부근, 무한형 맵은 플레이어 주변 활성 범위에서 플레이어와 일정 거리 이상 떨어진 위치를 선택한다.
	- 몸체가 맵 안의 보행 바닥 위에 있고 장애물·캐릭터와 겹치지 않도록 한다. 플레이어 바로 옆에 갑자기 생성하지 않는다.
	- 한 주기의 후보가 모두 실패하면 생성하지 않고 다음 주기로 넘긴다.

### 6.2 난이도 곡선 (엔드리스)

- 시간 경과에 따라 적의 출현 빈도를 높여 전투 압박을 증가시킨다.
- 현재 기본 곡선은 스폰 간격을 줄이는 방식이다. 동시 생성 수와 시간 함수의 구체값은 튜닝·확장 대상이다.
- 적 체력·공격력의 시간별 증가와 적 유형의 대량 확대는 포스트-MVP 범위다.
- 스폰 간격·최소 간격·시간별 감소량은 적 스포너 설정에서 조정한다.

| 조준 | 마우스 커서 방향 |
| 공격 | 클릭 또는 지정 키 |
| 획득·교체·드롭 | 상호작용 버튼 하나 |

- 근접·원거리 모두 조준 방향으로 공격한다. 장착·교체·드롭의 문맥별 동작은 5.4를 따른다.
- 조준 자동 보정의 채택 여부는 미정이다. 현재 조작 기준은 수동 조준이다.

### 6.4 플레이어 공격 판정

<a id="64-데미지-판정-방식"></a>

| 공격 | 명중 조건 | 피해 대상 |
|---|---|---|
| 근접 | 활성 타격 구간에 손·무기 판정과 접촉 | 한 공격에서 여러 적 명중 가능. 같은 적은 공격당 최대 1회 |
| 원거리 | 투사체와 접촉 | 최초 명중한 적 1명에게 피해를 주고 투사체 소멸 |

- 근접 공격은 다수의 적을 상대할 수 있도록 한 공격에서 여러 대상을 맞힐 수 있다. 범위 전체를 같은 순간에 일괄 타격한다는 의미는 아니다.
- 관통은 개별 무기의 후속 차별점 후보이며 현재 원거리 공통 규칙에는 포함하지 않는다.
- 투사체 속도·판정 크기는 무기별 조정값이다.

## 7. 성장과 기록

<a id="7-진행보상-구조"></a>

### 7.1 런 내 성장과 기록

<a id="71-런-내"></a>

- **XP 획득**
	- 적 사망 즉시 사전 정의된 XP 값을 플레이어에게 가산한다. 별도 XP 오브젝트는 필드에 생성하지 않는다.
	- 레벨업에 필요한 XP 곡선은 현재 XP 처리 코드의 기준값·성장률로 정의한다.
- **레벨업과 증강 선택**
	- 레벨업하면 최대 체력으로 회복하고 최대 3개의 증강 후보 중 1개를 선택한다.
	- 선택 가능한 증강이 3개보다 적으면 남은 후보만 표시하고, 없으면 증강 선택을 생략한다.
	- 선택 팝업이 표시되는 동안 게임을 일시정지해 선택에 집중할 수 있게 한다.
	- 증강 등장 확률은 동일하다.
- **증강 성장**
	- 같은 증강을 다시 선택하면 레벨이 오른다. 최대 레벨에 도달한 증강은 이후 선택 후보에서 제외한다.
	- 최대 레벨과 레벨별 총 효과는 증강마다 정의한다. 첫 레벨의 효과가 크거나 점진적으로 증가하는 구성 모두 가능하다.
	- 증강 최대 레벨·효과량은 XP 곡선과 별개의 밸런스 값이다. 구체값은 플레이테스트에서 조정한다.
	- 기본 증강 목록은 공격력·공격속도·이동속도·최대 체력 증가다.
	- 무기 내구도 증가 증강은 채택 여부와 소급 적용 규칙이 미정이다.
- **런 기록**
	- 생존시간·처치수를 실시간 HUD로 표시하고 사망 시점의 값을 로컬에 저장한다.
	- 저장된 기록을 보여주는 결과 화면은 별도 범위다.

### 7.2 런 간 기록과 발견

<a id="72-런-간-메타-진행"></a>

- 메타 진행은 런 내 전투력에 영향을 주지 않는 기록·발견 중심으로 구성한다.
- 무기는 해금 없이 처음부터 필드 조우 대상이 된다. 종류와 컨디션의 무작위성은 5.5·5.6을 따른다.
- 조건 달성과 발견 자체를 진행으로 삼아 별도 화폐 교환을 요구하지 않는다. 해금 뒤에도 무작위 조우를 기다리는 단계를 추가하지 않기 위한 방향이다.

| 요소 | 진행 조건 | 범위 |
|---|---|---|
| 칭호 | 누적 처치·생존시간·VeryGood 컨디션 무기 최초 획득 등의 조건 달성 | 과시·기록용, 전투력 영향 없음 |
| 무기 도감 | 무기를 실제로 획득하면 고유 무기별 발견 기록 | 무기별 슬롯 하나. 등급·컨디션 조합으로 슬롯을 늘리지 않음 |
| 런 기록 | 생존시간·처치수 저장 | 비교용 기록, 전투력 이득 없음 |

- 등급은 무기에 고정되고 컨디션은 런 한정 상태이므로 도감의 별도 분류 축으로 사용하지 않는다.
- 시스템과 최소 콘텐츠를 먼저 갖추고 실제 콘텐츠가 늘어나면 칭호·도감 목록을 확장한다. 최종 목록·개수는 미정이다.

## 10. MVP 범위 정의 (개발 착수 기준)

> 개발 착수 시 정한 초기 범위를 보존한 장이다. 현재 구현 상태나 후속 확장 후보의 채택 목록을 뜻하지 않는다.

**포함**
- 제한형 첫 맵에서 진행하는 엔드리스 서바이벌
- 근접/원거리 2종(확장 가능한 데이터 구조로 구현)
- 내구도 소모: 근접=명중 시, 원거리=발사 시
- 무기 슬롯 1개, 필드 스폰 + 자동 교체 + 수동 드랍 버튼
- 맨손 시작
- 유형별 공격 메커니즘을 사용하는 적(6.1 참고, 첫 유형·수량은 미확정)
- XP/레벨업 + 3택 증강 시스템(전역 스탯 적용)
- **키보드·마우스 조작 구현**
- 칭호(타이틀)·무기 도감 최소 세트 (화폐 없이 조건/발견 기반, 파워 무관. 7.2 참고)

**제외 (후순위)**
- 무기 등급/희귀도, 이동속도 페널티, 슬롯 확장
- 3번째 이상 무기 대분류
- 적 유형의 대량 확대(개별 역할 후보는 별도 채택)
- 무기 특화 증강
- 조준 자동 보정(스냅/자석)
- 스토리/세계관/최종 아트
- 무한형 맵
